Security first, by design

Payment software needs strict rules. These are built into the architecture.

Server-side secrets

Secret keys never appear in frontend code or in the repository.

Server-verified status

A redirect or URL change never marks a payment as successful.

Merchant isolation

Each merchant can only access their own records.

No card data stored

We never store card numbers, CVV or bank credentials.
